# 坦克大战 (Battle City)

一个用纯 HTML + CSS + JavaScript(Canvas)实现的经典坦克大战小游戏,单文件即可运行,无需任何依赖或构建工具。

## 运行方式

直接用浏览器打开 `index.html` 即可开始游戏。

## 玩法

- **目标**:保卫下方的基地(鹰),摧毁本关所有敌方坦克。
- 每关 20 辆敌军,场上最多同时出现 4 辆;击毁一辆得 100 分。
- 敌人会随机移动并开火,还会追踪你的位置;击毁基地或生命归零则游戏结束。
- 随着关卡提升,地图会加入钢墙、水障并变得更复杂。

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |

## 地图元素

- 🟫 **砖墙** — 可被子弹摧毁
- ⬜ **钢墙** — 无法被普通子弹摧毁
- 🌊 **水障** — 坦克与子弹均无法通过
- 🦅 **基地(鹰)** — 被摧毁则游戏失败
